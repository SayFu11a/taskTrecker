# Возвращение в профессию — трекер

Одностраничный трекер по плану возвращения во frontend: учёба, собеседования, поиск работы
и тренировки с уровнями **минимум / норма / максимум**.

## Что внутри

- **День** — чек-лист из 7 блоков (Ulbi TV, собеседования, LeetCode, hh.ru, новости Frontend,
  повторение/проект, физическая активность). Каждый блок отмечается уровнем: минимум, норма, максимум.
  Переключатель режима дня: плохой / обычный / хороший. Отдельный план «Плохой день» на 50 минут.
- **Неделя** — 7 дней с темами (JS, React, TS, браузер, практика, контрольный день, выходной)
  и этапы выхода на 7–8 часов за 8 недель.
- **Тренировки** — программа A/B на турнике и своём весе, подходы и повторения для каждой из
  8 недель, отметки тренировок, путь к первому подтягиванию, восстановление.
- **Прогресс** — серия дней, статистика за 30 дней, heatmap за 5 недель, какие блоки проседают,
  журнал LeetCode.
- **Правила** — 8 правил, которые не дают плану развалиться, и источники по Frontend.

## Запуск

Сайт статический, без сборки и зависимостей. Достаточно открыть `index.html`
или поднять любой статический сервер:

```bash
python3 -m http.server 8100
```

## Данные

Все отметки хранятся в `localStorage` браузера (ключ `vp-tracker-v1`). Бэкенда нет.
Сбросить всё можно на вкладке «Прогресс» → «Сбросить всё».

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка страницы |
| `styles.css` | оформление, тёмная тема, адаптив |
| `data.js` | весь контент плана: блоки, неделя, тренировки, правила |
| `app.js` | логика: отметки, статистика, рендер |

Контент правится в `data.js` — структура отделена от кода.
